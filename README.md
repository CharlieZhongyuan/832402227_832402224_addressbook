# Address Book (Extreme Programming Assignment)

## Introduction
A web-based address book application with bookmarking, multiple contact methods, and Excel import/export.

## Tech Stack
- Python 3 + Flask
- SQLite
- openpyxl
- HTML/CSS/JavaScript

## Installation
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt


## Start
python -m src.app
Open http://127.0.0.1:5000 in browser.

## Features
- Add, edit, delete contacts
- Bookmark (favorite) contacts
- Multiple contact methods per person (phone, email, social, address)
- Export contacts to Excel (.xlsx)
- Import contacts from Excel (.xlsx)
